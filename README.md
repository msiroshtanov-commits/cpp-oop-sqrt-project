# C++ OOP Sqrt Project

Це навчальний проект для вивчення основ об'єктно-орієнтованого програмування на C++.

## Структура проекту

- `root.h` - Заголовковий файл з декларацією функції root
- `root.cpp` - Реалізація функції root для обчислення квадратного кореня
- `main.cpp` - Основна програма (завдання 4-6)
- `print_name.cpp` - Програма для друку імені (завдання 9)
- `age_calculator.cpp` - Програма для розрахунку віку (завдання 10)
- `CMakeLists.txt` - Конфігурація для CMake
- `Makefile` - Makefile для компіляції з GCC

## Компіляція та запуск

### Використання GCC (Makefile)

```bash
# Компіляція всіх програм
make

# Запуск основної програми
./sqrt

# Запуск програми друку імені
./print_name

# Запуск програми розрахунку віку
./age_calculator

# Очищення об'єктних файлів
make clean
```

### Використання CMake

```bash
mkdir build
cd build
cmake ..
make

# Запуск
./sqrt
./print_name
./age_calculator
```

### Використання Microsoft Visual Studio

1. Створіть новий проект: File → New → Project → Console App
2. Додайте файли: root.h, root.cpp, main.cpp
3. Натисніть Build → Build Solution (F7)
4. Натисніть Debug → Start Debugging (F5)
